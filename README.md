# Equity Analyst Lab

A hands-on equity analysis project built to develop practical skills in financial statement analysis, valuation, Python, Excel, and model governance.

## Version 1

The first company analyzed is Microsoft (MSFT).

Version 1 will:

- Pull public financial data from SEC EDGAR.
- Build historical financial statements.
- Calculate key financial ratios and free cash flow.
- Build a simple DCF valuation.
- Create an auditable Excel model.
- Produce a two-page investment memo.

## Data Sources

SEC EDGAR and company filings are the source of truth for material financial figures. Other financial data providers may be used for convenience or cross-checking.

## Important

This project is for financial analysis and education. It uses public data only.

**This project does not place trades or write to brokerage accounts.**
